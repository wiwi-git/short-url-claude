# Link Number는 1부터 차례로 늘어나는 10진수

Short Link를 사람이 읽고 말로 전하기 쉽게 하려고, Link Number를 1부터 하나씩 늘어나는 10진수로 발급한다 (`/1`, `/2`, `/3`, ...). 그 대가로 누구나 번호를 차례로 넣어 다른 사람이 만든 Short Link를 모두 열어 볼 수 있으며, 이를 알고 받아들였다. 로그인이 없고 Short Link는 공개 정보로 취급하므로 감수할 만하다고 판단했다.

## Considered Options

- **base62 인코딩** (`/a`, `/Zx`): 더 짧지만 사람이 읽고 말하기 어렵다.
- **무작위 코드**: 번호를 차례로 훑어보는 것을 막지만, "단순 숫자"라는 목표와 맞지 않는다.

## Consequences

이미 퍼진 Short Link가 있으면 번호 체계를 바꾸기 어렵다. 비공개로 지켜야 하는 Original URL은 이 서비스에 맞지 않는다.
