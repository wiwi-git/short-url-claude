# 01: 개발 환경과 빈 Dioxus fullstack 앱

**Status:** ready-for-agent

- [ ] Dioxus CLI(`dx`)가 설치돼 있다
- [ ] 저장소 루트에 Dioxus fullstack 프로젝트가 있고, `dx serve`로 `/` 첫 화면이 뜬다
- [ ] `cargo test`가 (자리표시 테스트라도) 통과한다
