# 04: 잘못된 입력 거절

**What to build:** 방문자가 줄일 수 없는 입력으로 "줄이기"를 누르면, 무엇이 잘못됐는지 알려 주는 한국어 오류 문구를 보고, 입력칸의 내용은 그대로 남아 고칠 수 있다. 명세: `.scratch/short-url-mvp/spec.md`

**Blocked by:** 02 (Shorten과 Follow 기본 흐름)

**Status:** ready-for-agent

- [ ] Shorten이 다음을 각각 다른 거절 사유로 돌려준다: 빈 입력(공백만 있는 입력 포함), URL 형식 아님, http/https가 아닌 스킴, 2048자 초과, 이 서비스 자기 주소(`BASE_URL`과 호스트가 같음)
- [ ] 거절된 입력은 저장되지 않고 Link Number를 소모하지 않는다
- [ ] 화면이 거절 사유마다 다른 한국어 오류 문구를 보여 주고, 입력칸 내용을 유지한다
- [ ] 성공하면 오류 문구가 사라지고 새 결과가 이전 결과를 대체한다
- [ ] 경계 1 테스트: 거절 사유 각각, 그리고 거절 뒤 다음 성공 Shorten의 번호가 건너뛰지 않음
- [ ] 경계 2 테스트: Shorten 서버 함수가 거절 사유를 돌려줌
